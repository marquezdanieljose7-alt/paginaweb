# Lectura Libre — Biblioteca virtual

Página web estática desarrollada con HTML, CSS y JavaScript.

## Funciones
- Catálogo de 12 libros de ejemplo.
- Búsqueda por título, autor o categoría.
- Filtros por temática.
- Lista de favoritos durante la sesión.
- Ventana con detalles de cada libro.
- Diseño adaptable a celulares y computadores.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: estilos y diseño responsive.
- `script.js`: catálogo e interacciones.

## Cómo abrir
Abre `index.html` en tu navegador. No requiere instalación ni dependencias.

## Publicar con GitHub Pages
En el repositorio, entra a **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/(root)`, y guarda.

## Nota
Es una demostración académica. Los libros y descripciones son datos de ejemplo; no se distribuyen libros completos ni se realizan préstamos reales.
